# Component sources

Unlumen UI, Magic UI, and SmoothUI are optional source libraries only.

Rules:
- Do not expose library branding in the product.
- Do not adopt a library's visual identity wholesale.
- Do not import source components directly into product views when an APEX3X-owned adapter is appropriate.
- Preserve the existing APEX3X visual foundation as the authority.
- Reuse the repository's existing Motion dependency.
- Prefer the smallest useful source component for a real product requirement.
